# Saransh Pareek — Portfolio

An interactive, cinematic portfolio featuring dynamic dual-theme switching with a physics-driven pull-cord, interactive project simulators, smooth Lenis scrolling, GSAP cinematic typography, and full project showcases.

Live on Vercel: connected via automated CI/CD.

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite 6
- **Styling**: Tailwind CSS v4 + Custom Design Tokens (Cinematic Dark & Neo-Editorial Light)
- **Physics & Motion**: Framer Motion + GSAP ScrollTrigger + Lenis Smooth Scroll
- **Interactive Features**: Verifiable live interactive project simulators (EduCloud, Gram Sathi, Quiz Master), dynamic live search palette (`Cmd+K` / `Ctrl+K`), custom cursor, and particle embers field.

## Getting Started

You need [Node.js](https://nodejs.org) 18 or newer.

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.

## Build for Production / Vercel

```bash
npm run build
```

The output will be built into `dist/`.
